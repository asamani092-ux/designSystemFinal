# نظام الزاد الموحّد — عقود المكوّنات (Component Contracts)

> **المستوى 2.** العقد هو ما يُنقل بين المنصات؛ الكود مجرد تنفيذ له. لا تبدأ تنفيذ أي مكوّن قبل اعتماد عقده.
> كل الألوان والمسافات تُشتق من `tokens.css` عبر `var(--*)` — لا قيم صريحة في التنفيذ.

## المبادئ الحاكمة
1. **RTL أولاً بلا استثناء** — كل الواجهة من اليمين لليسار: النصوص والحقول والأرقام والأيقونات الاتجاهية. استخدم الخصائص المنطقية (`inline-start/end`, `margin-inline`, `padding-inline`) لا `left/right`.
2. **مستقل عن أي منصة** — لا shadcn/Material/Bootstrap/مكوّنات منشئ مواقع. HTML + CSS نقي بمتغيرات فقط.
3. **دلالي لا وصفي** — `--surface-raised` لا `gray-100`؛ `--text-brand` لا `maroon`.
4. **الوصول شرط قبول** — تباين ≥ 4.5:1 للنص، ≥ 3:1 للعناصر الرسومية؛ تركيز مرئي؛ ترتيب تبويب منطقي؛ ARIA مطابق؛ لمس ≥ 44×44px؛ نص ≥ 14px.
5. **تبديل العلامة بمتغيّر واحد** — إعادة تعريف `--brand-primary` (ومعه `--primary-*`) تبدّل النظام كله. مثبت بمثال `data-brand="teal"` في `tokens.css`.

## اصطلاح العقد
لكل مكوّن: **الغرض · الخصائص (props) · الحالات · RTL · الوصول · إعادة التنفيذ (React / Apps Script / بلا كود)**.
الحالات القياسية المشتركة: `default · hover · focus-visible · active · disabled · loading · error · empty` (حيثما تنطبق).

## 1) الأساسيات

### 1.1 الزر — Button
- **الغرض:** إطلاق إجراء واحد واضح.
- **الخصائص:** `variant: primary | secondary | accent | ghost | danger` · `size: sm(36) | md(44) | lg(52)` · `icon?: start|end` · `iconOnly?: bool` · `loading?: bool` · `disabled?: bool` · `fullWidth?: bool`.
- **الحالات:** default→`--action-primary-surface`؛ hover→`-hover`؛ active→`-active`؛ focus-visible→حلقة `--shadow-focus`؛ disabled→`opacity .55` + `cursor:not-allowed`؛ loading→سبينر + تعطيل النقر مع الحفاظ على العرض.
- **RTL:** الأيقونة `start` تقع يمين النص؛ سهم التقدّم = يسار (`←`).
- **الوصول:** `<button>` حقيقي؛ `aria-busy` في loading؛ `aria-label` لِـ iconOnly؛ ارتفاع ≥ 44 لِـ md.
- **إعادة التنفيذ:** React `<Button variant>`؛ Apps Script: `<button class="zad-btn zad-btn--primary">` + CSS؛ بلا كود: زر مع كلاس مخصّص وربط `tokens.css`.

### 1.2 حقل النص — TextField
- **الغرض:** إدخال سطر نصي.
- **الخصائص:** `label` (إلزامي) · `type: text|email|tel|number|password|search` · `dir: auto` (RTL افتراضاً، لكن القيمة الرقمية/البريد تعرض LTR داخلياً مع محاذاة البدء) · `placeholder` · `hint?` · `error?` · `prefix/suffix?` (أيقونة) · `required` · `disabled` · `readOnly`.
- **الحالات:** default حد `--border-default`؛ focus حد `--border-focus` + حلقة؛ error حد `--danger-solid` + نص `--danger-text` + `aria-invalid`؛ disabled خلفية `--surface-sunken`.
- **RTL:** التسمية والرسالة يمين؛ أيقونة البحث في `inline-start`؛ الأرقام تُعرض ضمن سياق RTL بلا قلب المعنى.
- **الوصول:** `label[for]`؛ `aria-describedby` للتلميح/الخطأ؛ تباين نص التلميح ≥ 4.5:1.
- **إعادة التنفيذ:** React `<TextField error>`؛ Apps Script: `<label>` + `<input>`؛ بلا كود: حقل نموذج + كلاس.

### 1.3 القائمة المنسدلة — Select
- **الغرض:** اختيار قيمة واحدة من قائمة.
- **الخصائص:** `label` · `options[]{value,label,disabled?}` · `placeholder` · `searchable?` · `error?` · `disabled`.
- **الحالات:** مغلق/مفتوح؛ عنصر مميّز (highlight) `--primary-50`؛ عنصر مختار علامة ✓؛ فارغ «لا نتائج».
- **RTL:** فتح القائمة محاذى للبدء؛ سهم الفتح في `inline-end`.
- **الوصول:** `role=listbox/option`، `aria-expanded`، تنقّل بالأسهم + Enter + Esc.
- **إعادة التنفيذ:** React مخصّص أو `<select>` أصلي؛ Apps Script: `<select>` أصلي (الأبسط)؛ بلا كود: عنصر Dropdown + كلاس.

### 1.4 الاختيار المتعدد — MultiSelect / Combobox
- **الغرض:** اختيار عدة قيم مع وسوم.
- **الخصائص:** `options[]` · `value[]` · `max?` · `creatable?` · `searchable`.
- **الحالات:** وسوم مختارة قابلة للحذف (×)؛ عداد «+N»؛ تجاوز الحد يعطّل الإضافة.
- **RTL:** الوسوم تتدفّق من اليمين؛ × في `inline-start` للوسم.
- **الوصول:** كل وسم زر حذف بـ `aria-label`؛ إعلان العدد المختار.

### 1.5 التبديل — Switch
- **الغرض:** تشغيل/إيقاف فوري.
- **الخصائص:** `checked` · `disabled` · `label` · `size`.
- **الحالات:** on `--action-primary-surface`؛ off `--border-default`؛ focus حلقة؛ حركة `--duration-fast`.
- **RTL:** المقبض في on ينزلق إلى `inline-start`.
- **الوصول:** `role=switch` + `aria-checked`؛ مساحة لمس ≥ 44.

### 1.6 مربع الاختيار / زر الراديو — Checkbox / Radio
- **الخصائص:** `checked/selected` · `indeterminate?` (checkbox) · `label` · `name` (radio group) · `disabled` · `error`.
- **الحالات:** محدّد `--action-primary-surface`؛ indeterminate شرطة؛ focus حلقة.
- **الوصول:** عنصر أصلي مفضّل؛ التسمية قابلة للنقر؛ المجموعة `role=radiogroup`.

### 1.7 منتقي التاريخ — DatePicker (هجري/ميلادي)
- **الغرض:** اختيار تاريخ مع تبديل التقويم.
- **الخصائص:** `calendar: hijri | gregorian | both` · `value` · `min/max` · `format` · `disabledDates?`.
- **الحالات:** اليوم مميّز؛ المختار `--action-primary-surface`؛ خارج النطاق معطّل؛ تبديل هجري/ميلادي سطر علوي.
- **RTL:** الشبكة تبدأ بالسبت يميناً؛ أسهم التنقّل معكوسة الاتجاه.
- **الوصول:** تنقّل لوحة مفاتيح كامل؛ إعلان الشهر/السنة؛ `aria-selected`.
- **إعادة التنفيذ:** React مكتبة تقويم محايدة أو مخصّص؛ Apps Script: حقل + تقويم منبثق مخصّص؛ بلا كود: عنصر تاريخ + تحويل هجري عبر سكربت.

### 1.8 الشارة والوسم — Badge / Tag
- **الغرض:** حالة (badge) أو تصنيف قابل للحذف (tag).
- **الخصائص:** `tone: neutral|brand|success|warning|danger|info` · `variant: soft|solid|outline` · `removable?` (tag) · `dot?`.
- **RTL:** × في `inline-start`؛ النقطة قبل النص (يمين).
- **الوصول:** الحالة تُعلن نصاً لا لوناً فقط؛ زر الحذف `aria-label`.

### 1.9 التنبيه — Alert
- **الخصائص:** `tone: success|warning|danger|info` · `title` · `body?` · `dismissible?` · `action?`.
- **RTL:** الأيقونة `inline-start`؛ شريط ملوّن `border-inline-start`.
- **الوصول:** `role=status` (info/success) أو `role=alert` (danger)؛ اللون + أيقونة + نص معاً.

### 1.10 النافذة الحوارية — Dialog / Modal
- **الخصائص:** `title` · `size: sm|md|lg` · `dismissible` · `footerActions[]` · `variant: default|confirm|destructive`.
- **الحالات:** فتح مع تعتيم `--z-overlay`؛ حبس التركيز؛ Esc يغلق؛ منع تمرير الخلفية.
- **RTL:** الإجراءات الأساسية جهة البدء (يمين)؛ × في `inline-end` للعنوان.
- **الوصول:** `role=dialog` `aria-modal` `aria-labelledby`؛ إعادة التركيز للمُطلق عند الإغلاق.

### 1.11 التلميح — Tooltip
- **الخصائص:** `content` · `placement: top|bottom|start|end` · `delay`.
- **الوصول:** `aria-describedby`؛ يظهر بالتركيز لا التحويم فقط؛ لا يحمل معلومة حرجة وحيدة.

### 1.12 مؤشر التحميل — Spinner / Skeleton
- **الخصائص:** `type: spinner|skeleton` · `size` · `lines?` (skeleton).
- **الوصول:** `role=status` + `aria-live=polite` + نص «جارٍ التحميل»؛ skeleton يطابق أبعاد المحتوى.

### 1.13 حالة الفراغ — EmptyState
- **الخصائص:** `icon` · `title` · `body?` · `action?`.
- **الوصول:** عنوان واضح؛ الإجراء زر حقيقي.

## 2) التخطيط

### 2.1 شبكة 12 عمود — Grid
- **الخصائص:** `cols: 12` · `gap: space-token` · `colspan` لكل عنصر · نقاط كسر متجاوبة.
- **RTL:** التدفّق من اليمين؛ `grid` منطقي تلقائياً.
- **إعادة التنفيذ:** CSS Grid؛ Apps Script نفس CSS؛ بلا كود: نظام أعمدة المنشئ مع gap من التوكن.

### 2.2 البطاقة — Card
- **الخصائص:** `padding` · `raised?` (ظل) · `interactive?` (hover) · slots: header/media/body/footer.
- **الحالات:** interactive → hover ظل أعلى + `cursor`.
- **الوصول:** إن كانت كلها رابطاً فزر/رابط واحد يلفّها.

### 2.3 اللوح — Panel / Section
- **الخصائص:** `title` · `actions?` · `collapsible?` · `padding`.
- **الوصول:** العنوان `<h*>` بمستوى صحيح.

### 2.4 الفاصل — Divider
- **الخصائص:** `orientation` · `label?` · `inset?`. **الوصول:** `role=separator`.

### 2.5 الشريط الجانبي القابل للطي — Sidebar
- **الخصائص:** `items[]{icon,label,badge?,active}` · `collapsed?` · `footer?`.
- **الحالات:** موسّع 264px / مطوي 72px (أيقونات فقط + tooltip)؛ البند النشط خلفية `--primary-50` ونص `--text-brand`.
- **RTL:** يُثبّت جهة البدء (اليمين)؛ سهم الطي معكوس.
- **الوصول:** `nav` + `aria-current=page`؛ زر الطي بحالة `aria-expanded`.

### 2.6 الشريط العلوي — TopBar / AppBar
- **الخصائص:** `logo` · `nav?` · `search?` · `actions[]` · `user`.
- **RTL:** الشعار يمين؛ إجراءات المستخدم يسار.
- **الوصول:** `header` + `nav`؛ الأزرار الأيقونية بـ `aria-label`.

### 2.7 مسار التنقّل — Breadcrumb
- **الخصائص:** `items[]{label,href?}`؛ الأخير حالي بلا رابط.
- **RTL:** الفواصل تشير لليسار (اتجاه التقدّم)؛ التدفّق من اليمين.
- **الوصول:** `nav[aria-label=breadcrumb]` + `aria-current=page`.

## 3) البيانات

### 3.1 الجدول — DataTable
- **الغرض:** عرض صفوف بيانات مع تحكّم.
- **الخصائص:** `columns[]{key,label,sortable?,align,width?}` · `rows[]` · `sort` · `filter` · `pagination{page,size,total}` · `selectable?` (checkbox) · `onExport` · `stickyHeader?`.
- **الحالات:** فرز تصاعدي/تنازلي بسهم؛ صف محدّد `--primary-50`؛ hover صف؛ loading skeleton صفوف؛ empty حالة فراغ داخل الجسم؛ error شريط + إعادة محاولة.
- **RTL:** أول عمود يمين؛ محاذاة الأرقام حسب المنطق؛ سهم الفرز صحيح الاتجاه.
- **الوصول:** `<table>` دلالي، `<th scope>`، `aria-sort` على الرأس، تحديد الصف مربوط بـ `aria-label`.
- **التجاوب:** < 768px يتحوّل إلى **بطاقات** (صف = بطاقة، الرأس = تسميات داخلية)، لا تصغير أعمى.
- **إعادة التنفيذ:** React `<DataTable>`؛ Apps Script: HTML table + فرز/ترشيح بـ JS + تصدير عبر `google.script.run`؛ بلا كود: جدول المنشئ + كلاسات.

### 3.2 القائمة — List
- **الخصائص:** `items[]` · `divided?` · `leading/trailing slots` · `selectable?`.
- **الوصول:** `<ul>/<li>` أو `role=list`؛ العناصر التفاعلية أزرار/روابط.

### 3.3 شريط أدوات الترشيح — FilterBar
- **الخصائص:** `filters[]{type: select|search|dateRange|chips}` · `applied[]` (وسوم قابلة للحذف) · `onClear`.
- **RTL:** الوسوم المطبّقة تتدفّق من اليمين؛ «مسح الكل» جهة البدء.
- **الوصول:** كل مرشّح مسمّى؛ إعلان عدد النتائج بعد الترشيح.

## 4) المؤشرات (تشتق ألوانها من التوكنات)

### 4.1 بطاقة KPI
- **الخصائص:** `label` · `value` · `delta{value,direction: up|down|flat}` · `comparison?` · `icon?` · `spark?`.
- **الحالات:** اتجاه صاعد `--success-text`، هابط `--danger-text`، ثابت `--text-muted`.
- **RTL:** الأيقونة يمين؛ اتجاه السهم بصري لا يحمل معنى اللغة.
- **الوصول:** القيمة والدلتا نص مقروء؛ اللون + أيقونة سهم معاً.

### 4.2 المخططات — Charts (خطي / أعمدة / دائري / تقدّم)
- **الغرض:** تمثيل بصري موحّد الألوان.
- **الخصائص:** `type: line|bar|pie|progress` · `series[]` · `palette` (يشتق: `--primary-500, --secondary-400, --info-solid, --success-solid...`) · `legend` · `axis` · `emptyState`.
- **RTL:** المحور السيني يبدأ من اليمين؛ التسميات والأسطورة يمين؛ الاتجاه الزمني يمين→يسار.
- **الوصول:** بديل نصي/جدول مكافئ؛ لا تعتمد على اللون وحده (نقش/تسمية)؛ تباين السلاسل ≥ 3:1.
- **إعادة التنفيذ:** React مكتبة محايدة (Recharts/uPlot) بألوان التوكنات؛ Apps Script: SVG مولّد أو صورة مخطط؛ بلا كود: أداة مخطط + استبدال الألوان بالتوكنات.

### 4.3 شريط التقدّم — Progress
- **الخصائص:** `value 0–100` · `tone` · `label?` · `indeterminate?`.
- **الوصول:** `role=progressbar` + `aria-valuenow/min/max`.

## 5) التقارير

### 5.1 رأس التقرير — ReportHeader
- **الخصائص:** `logo` (أفقي) · `title` · `meta{date,ref,preparedBy}` · `period`.
- **الطباعة:** يظهر أعلى كل صفحة مطبوعة؛ الشعار أعلى اليمين.

### 5.2 منطقة المعايير — ReportCriteria
- **الخصائص:** `criteria[]{label,value}` — ملخّص المرشّحات المطبّقة على التقرير.

### 5.3 جدول التقرير — ReportTable
- مثل DataTable لكن بلا تفاعل عند الطباعة (بلا فرز/ترقيم على الورق)؛ صفوف متناوبة خفيفة؛ مجاميع في التذييل.

### 5.4 أنماط الطباعة — `@media print`
- A4، هوامش 16mm، بلا تنقّل/أشرطة جانبية/ظلال، ألوان نص داكنة على أبيض، `page-break-inside: avoid` للصفوف والبطاقات، رأس/تذييل مكرّر، روابط تُطبع نصاً.

## 6) المهام

### 6.1 بطاقة المهمة — TaskCard
- **الخصائص:** `title` · `priority` · `status` · `assignee` · `due{date, overdue?}` · `tags[]` · `progress?`.
- **الحالات:** متأخّرة → تاريخ `--danger-text`؛ سحب (dragging) ظل مرفوع.
- **الوصول:** قابلة للتشغيل بلوحة المفاتيح؛ الأولوية/الحالة نص لا لون فقط.

### 6.2 لوح الأعمدة — KanbanBoard
- **الخصائص:** `columns[]{id,title,limit?}` · `cards[]` · `onMove`.
- **الحالات:** منطقة إفلات مميّزة؛ تجاوز الحد (WIP) تحذير.
- **RTL:** الأعمدة تتدفّق من اليمين.
- **التجاوب:** < 768px يتحوّل إلى **تبويبات** (تبويب لكل عمود) لا تمرير أفقي أعمى.
- **الوصول:** بديل لوحة مفاتيح للسحب (نقل عبر قائمة/أزرار)؛ إعلان النقل.

### 6.3 شارة الأولوية / الحالة — PriorityBadge / StatusBadge
- **الخصائص:** `priority: low|medium|high|urgent` · `status: todo|in-progress|review|done|blocked` — كلاهما نص + أيقونة + لون من التوكنات.

### 6.4 المسند إليه — AssigneeAvatar
- **الخصائص:** `name` · `image?` · `group?` (مجموعة متراكبة + «+N»). دوائر ملوّنة بلا أحرف افتراضاً.

### 6.5 الخط الزمني — Timeline
- **الخصائص:** `events[]{time,title,body?,tone,icon?}`.
- **RTL:** المحور جهة البدء (يمين)؛ الترتيب من الأحدث/الأقدم واضح.
- **الوصول:** قائمة مرتّبة دلالية.

## 7) المرفقات والشواهد

### 7.1 منطقة السحب والإفلات — Dropzone
- **الخصائص:** `accept[]` · `maxSize` · `multiple?` · `onFiles`.
- **الحالات:** default منقّطة؛ dragover مميّزة `--primary-50`؛ رفض نوع/حجم تحذير فوري.
- **RTL:** النص والأيقونة توسّط؛ التعليمات يمين.
- **الوصول:** زر «استعراض» بديل للسحب؛ `aria-label`؛ دعم لوحة المفاتيح.

### 7.2 صف الملف — FileRow
- **الخصائص:** `name` · `type` · `size` · `progress?` · `status: uploading|done|error` · `onRemove` · `onRetry`.
- **الحالات:** uploading شريط تقدّم؛ done ✓؛ error نص `--danger-text` + «إعادة محاولة».
- **RTL:** الأيقونة يمين؛ الحجم/التقدّم يسار؛ × في `inline-start`.
- **الوصول:** الحالة نصية؛ الأزرار بـ `aria-label`.

### 7.3 معاينة الصورة/المستند — FilePreview
- **الخصائص:** `type: image|pdf|doc` · `src` · `zoom?` · `download`.
- **الوصول:** صورة بـ `alt`؛ PDF ببديل رابط تنزيل.

### 7.4 حالات الخطأ — UploadErrors
- أنواع: **نوع غير مدعوم** (اذكر الأنواع المسموحة)، **حجم زائد** (اذكر الحد)، **فشل رفع** (+ إعادة محاولة)، **انقطاع اتصال**. كلها نص + أيقونة + إجراء تعافٍ.

## 8) الاستجابة — تجاوب منطقي لا تصغير أعمى

**نقاط الكسر:** `xs 360 · md 768 · lg 1024 · xl 1440 · 2xl 1920`.
استخدم **container queries** حين يعتمد المكوّن على وعائه لا الشاشة (بطاقة داخل شبكة، لوح داخل عمود).

| المكوّن | سلوك التحوّل |
|---|---|
| الجدول (DataTable) | ← بطاقات على < 768 |
| الشريط الجانبي | ← درج (drawer) منزلق على < 1024 |
| الكانبان | ← تبويبات (تبويب/عمود) على < 768 |
| لوحة المؤشرات | ← عمود واحد بترتيب أولوية محدّد على < 768 |
| الشريط العلوي | ← قائمة همبرغر تجمع التنقّل على < 768 |
| النموذج متعدد الأعمدة | ← عمود واحد على < 768 |

**ثوابت:** لمس ≥ 44×44px، نص ≥ 14px، لا فقدان وظيفة عند التصغير (تُنقل لا تُحذف).

## 9) قائمة التحقّق للنقل إلى منصة جديدة

1. **اربط الأساس:** انسخ `tokens.css` واربطه، وأضف `class="zad-root" dir="rtl"` على الجذر. حمّل خط Tajawal.
2. **اضبط العلامة:** أبقِ `--brand-primary` أو بدّله لجهة فرعية عبر `data-brand`. لا تكتب ألواناً صريحة.
3. **الثيم:** فعّل `data-theme="light|dark"` على الجذر (أو اترك تفضيل النظام).
4. **نفّذ من العقد:** لكل مكوّن ابدأ من عقده في هذا الملف؛ استخدم `var(--*)` حصراً.
5. **الوصول:** تحقّق تباين 4.5:1، تركيز مرئي، ترتيب تبويب، ARIA، لمس 44px.
6. **التجاوب:** طبّق سلوك التحوّل (جدول 3.1، §8) لا التصغير.
7. **الطباعة:** ضمّن `@media print` للتقارير (§5.4).

### ماذا حين لا يوجد مكوّن مقابل على المنصة؟
- **المسموح:** ابنِ المكوّن من عناصر HTML أولية (`button/input/table/div`) + `tokens.css`؛ أو استخدم مكوّناً محايداً وأعد تلوينه بالتوكنات فقط؛ حافظ على العقد (الخصائص/الحالات/الوصول/RTL) حرفياً.
- **الممنوع:** استيراد مكتبة UI كاملة تفرض هويتها؛ استخدام ألوان/مسافات/أنصاف خارج التوكنات؛ إسقاط حالة من العقد (خصوصاً focus/disabled/error/empty)؛ كسر RTL بـ `left/right` صريحة؛ نص < 14px أو لمس < 44px.
